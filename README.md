<h1 align="center">🗄️ JS Session Storage</h1>

<p align="center"><img src="https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white" alt="HTML5"> <img src="https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=white" alt="JavaScript"></p>

<p align="center">JavaScript'da <code>sessionStorage</code>, <code>setInterval</code> va <code>setTimeout</code> bilan ishlash bo'yicha mashq.</p>

## 📖 Nimani o'rgatadi

- `sessionStorage.setItem()` bilan ma'lumot saqlash va `length` ni tekshirish
- `setInterval()` — har soniyada joriy vaqtni konsolga chiqarish
- `setTimeout()` + `clearInterval()` — 3 soniyadan so'ng intervalni to'xtatish

## 🚀 Ishga tushirish

Hech qanday o'rnatish kerak emas:

```bash
git clone https://github.com/Zikrillayev77/Js-Session-storage.git
cd Js-Session-storage
```

So'ng `index.html` faylini brauzerda oching (yoki VS Code'dagi **Live Server** kengaytmasi orqali).

Natijani ko'rish uchun brauzer konsolini oching (**F12 → Console**).
